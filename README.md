# Bhavya Sharma · Clinic Website Portfolio

One-page portfolio for a web designer who builds websites for clinics.
Plain HTML, CSS and JavaScript. No build step, no dependencies.

## Look
Graphite & Acid Lime. Space Grotesk headings, Manrope body text (fonts included in /fonts).
Colours are the variables at the top of style.css.

## Files
index.html     page markup
style.css      all styles, including the 3D stage and the project reveal animation
app.js         scroll-driven 3D mockup engine
mittra.png     screenshot, Mittra Clinic
delhi.png      screenshot, Delhi Clinic
randhawa.png   screenshot, Randhawa Clinic
fonts/         Space Grotesk and Manrope (woff2)

## Run locally
Open index.html in a browser.
